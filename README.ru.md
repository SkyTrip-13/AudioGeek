# AudioGeek: статьи по электронике и звуку

Архив блога **[audiogeek.ru](https://audiogeek.ru)** Андрея Небесного (Andrew Nebesny): практические статьи про аналоговую электронику, звуковые схемы, наушники, винил и самоделки. Сайт перестал работать в 2026 году, а статьи живут здесь, на русском и английском языках.

- **57 статей**
- У каждой статьи своя папка с текстом и всеми картинками:
  - `README.ru.md`: русский (оригинал)
  - `README.md`: английский
- Вверху каждой статьи есть переключатель языка и ссылка на оригинальную публикацию.
